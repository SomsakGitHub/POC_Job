Hitch checks with 200 ms injected (26 November 2026)

What was run: the Release app built from commit f7af071, on the iPhone 18 Pro simulator (iOS 27.2), against the Release
exchange server on the same Mac. Lab: extraLatencyMs 200, everything else at its default. The app was launched with
--print-latency, and with --open-symbol PTT in every run except the first. Each run lasted 32 seconds. The figure is the
last line the app printed, which is cumulative since the launch.

for the whole run.
